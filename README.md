# Next.js template

This is a Next.js template with shadcn/ui.

## Environment

Copy `.env.example` to `.env` and fill in the values:

```bash
cp .env.example .env
```

- `DATABASE_URL` - PostgreSQL connection string.
- `BETTER_AUTH_SECRET` - Secret used to sign sessions (`openssl rand -base64 32`).
- `BETTER_AUTH_URL` - Base URL of the app (`http://localhost:6001` in development).

## Database migrations

The schema lives in `src/lib/db/schema.ts` and migrations are stored in `drizzle/`.
Drizzle Kit is configured through `drizzle.config.ts`.

Apply the existing migrations to your database:

```bash
npm run db:migrate
```

After changing `src/lib/db/schema.ts`, generate a new migration and apply it:

```bash
npm run db:generate
npm run db:migrate
```

For quick local prototyping you can push the schema directly without generating a
migration file (not recommended for production):

```bash
npm run db:push
```

Open Drizzle Studio to inspect the database:

```bash
npm run db:studio
```

### Auth schema

The auth tables (`user`, `session`, `account`, `verification`, `passkey`) are
generated by Better Auth. After changing `src/lib/auth.ts` (e.g. adding a plugin),
regenerate the schema, then generate and apply a migration:

```bash
npm run auth:generate
npm run db:generate
npm run db:migrate
```

## Adding components

To add components to your app, run the following command:

```bash
npx shadcn@latest add button
```

This will place the ui components in the `components` directory.

## Using components

To use the components in your app, import them as follows:

```tsx
import { Button } from "@/components/ui/button";
```
